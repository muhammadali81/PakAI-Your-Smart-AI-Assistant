# Pak AI - Pakistan's Premier AI Assistant & Productivity Super App

**Pak AI** is an advanced native Android application built with **Kotlin** and **Jetpack Compose**, integrated with Google's **Gemini API**.

Developed with pride by **Muhammad Ali** (`alimuhammadhvn81@gmail.com`).

---

## 🚀 Key Features

1. **AI Chat (Gemini 3.5 Flash)**
   - Conversational multi-turn memory
   - Deep Thinking Mode & Web Search simulation
   - Rich Markdown, syntax highlighting, and text-to-speech audio

2. **Voice Command Assistant**
   - Natural spoken input in English and Urdu
   - Voice routing to tools, slide maker, and task manager

3. **PDF Maker Studio**
   - Generate formal PDF documents, executive reports, resumes, and study guides
   - Built on native Android `PdfDocument` engine with instant view & share

4. **Presentation PPT Slides Maker**
   - 16:9 widescreen presentation slides with speaker notes
   - Generates interactive, standalone HTML5 presentation slide decks

5. **Photo Editor Studio & AI Vision Lens**
   - Live photo filters (brightness, contrast, saturation, sharpness, vignette)
   - Multimodal image reasoning with Google Gemini

6. **100+ Languages Polyglot Studio**
   - Translate across 100+ languages including Urdu, Pashto, Punjabi, Sindhi, Balochi, Arabic, French, and Chinese
   - Audio pronunciation and one-tap save to Task Manager

7. **Task Manager**
   - Offline Room database persistence with priority badges and category filters

## 🛠️ How to Build & Run the Android App

### Requirements
- Android Studio Ladybug or newer
- JDK 17
- Android SDK 26+ (Target SDK 34)

### Steps:
```bash
# 1. Clone repository
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>

# 2. Set your Gemini API Key in .env
echo "GEMINI_API_KEY=your_key_here" > .env

# 3. Build debug APK
gradle assembleDebug

# Output APK:
# app/build/outputs/apk/debug/app-debug.apk
```
