How to Build & Run on Android

Follow these quick steps to run Pak AI on any Android device or emulator (Android 8.0 / API 26 or higher):

# 1. Clone your repository git clone https://github.com/<your-username>/<your-repo>.git cd <your-repo> # 2. Add your Google Gemini API key to .env or Android Secrets echo "GEMINI_API_KEY=your_gemini_api_key_here" > .env # 3. Build the Debug APK using Gradle gradle assembleDebug # 4. The generated APK will be available at: # app/build/outputs/apk/debug/app-debug.apk

Alternatively, simply open the project in Android Studio (Ladybug or newer), click Sync Project with Gradle Files, and press Run (Shift + F10) on your physical device or virtual emulator.
